## 已实现

- 不依赖登记处的材料交接、单独评分参考导出、离线重跑及收到回执的一致性检查。绑定另行保存的包摘要；拒绝未知文件、篡改和可执行评分器，保留失败、未知、环境/引擎变化。
- 旧观察重算明确计为零新增观察、零新增独立样本。外部使用者的实际反馈可以原样附入，但身份和独立性不会由回执或哈希自动认证。
- 限定 host/model/plugin/replicate 的比较入口，要求明确版本、内容指纹、观察时间和谱系；禁止把多项同时变化或同研究补证当成独立因素效果。
- 事前冻结质量、成本、失败风险界限；依据原始记录生成逐场景使用建议，保留不适用条件、负结果和复核要求。区分基线进步与启用结果下降的描述性模式；不把零均值差推导为无用或永久停用。
- 真实历史先导研究及 P1 供体差异分析材料的一次性交接脚本；支持相同观察复核和显式参考后端复算，不自动启动模型调用。

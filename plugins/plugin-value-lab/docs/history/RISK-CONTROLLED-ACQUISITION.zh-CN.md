# 同一错误风险约束下的决策效率

目标是：在相同错误选择风险、相同决策用途和足够的有效决策比例下，减少实验负担。仅运行次数下降、提前停止或放弃更多任务，都不能证明效率提升。

现有 `evidence_acquisition` 保持原义：它按决策相关性和费用组织筛选、保留独立确认，`statistical_guarantee=NONE`。新 `context.risk_acquisition` 是独立的前瞻模式，通过现有 `plan_plugin_use` / `plan-use` 使用，不混用旧筛选历史，也不替代单插件评估或完整科研检查。

## 先冻结“什么算同样有用”

每项新协议必须固定以下内容，结果出来后不能改阈值、删除候选或扩大观察上限来获取通过：

| 契约 | 含义 |
| --- | --- |
| 有界效用 | 研究任务的评分规则及来源，范围 `[0,1]`；不能用插件数量代替效用 |
| `epsilon` | 可容忍的期望效用损失；选择的候选最多比真实最佳候选差多少 |
| `quality_floor` | 选择仍必须达到的绝对效用下限 |
| `alpha` | 一次冻结研究中，错误签发选择／错误宣告全部不可用的联合概率上界 |
| 候选范围 | 完整方案摘要、明确的无插件基线；结论只限该集合 |
| 抽样单位与总体 | 独立任务实例、抽样规则、目标分布身份；同一任务内重复运行应先聚合为一个单位 |
| 观察与预算上限 | 每候选最大单位数、每批单位数、每单位计划运行数、完整实验费用上限和总单位预算 |

当前决策目标是“期望效用不低于下限，且距冻结候选中的最佳期望效用不超过 epsilon”。它不证明全目录最少插件数，也不把平均效用当成每个关键科学检查均通过。

一份有用决定可以是选择候选，也可以是有证据地判断“所有候选均达不到效用下限”。到达预算、仍无法区分或抽样假设不成立，则保留未决；未决不算成功决策。

**相同风险上界不等于真实错误概率严格相等。** 当前提供的是同一统计约束下的比较；实际风险与效率还需要独立适用性检查和实证校准。

alpha 只覆盖这一份冻结研究的整个候选与查看范围。反复重启协议、更换候选后只汇报最好的一次，不在同一保证内；跨研究检验族需要单独预分配总错误预算。文件摘要绑定内容，不能证明冻结时间或没有其他未报告研究。

## 有限观察范围内的停止依据

设冻结候选数为 `K`，每候选最多观察 `H` 个独立单位，效用 `X` 在 `[0,1]` 内。同一候选的单位来自固定总体，均值为 `mu_i`；下一批分配必须在看到该批结果之前确定。声明这些条件不会验证它们确实成立。

第 `n` 个样本时采用保守 Hoeffding 半径：

```text
r(n) = sqrt(log(2*K*H/alpha) / (2*n))
L_i = max(0, mean_i - r(n_i))
U_i = min(1, mean_i + r(n_i))
```

没有观察的候选保留 `[0,1]`。每个候选、每个可能的局部样本量，其两侧超界概率至多 `alpha/(K*H)`；对全部 `K*H` 个事件求联合界，总超界概率至多 `alpha`。因此在这些条件和有限上限内，自适应分配、反复查看和停止不需要把普通固定样本区间冒充连续有效区间。

只有存在候选 `i` 同时满足以下条件时，才返回 `CERTIFIED_CANDIDATE`：

```text
L_i >= quality_floor
L_i >= max(U_j for j != i) - epsilon
```

若全部 `U_i < quality_floor`，才宣告 `CERTIFIED_NO_ACCEPTABLE_CANDIDATE`。在全部区间覆盖事件上，两种宣告均正确。因此“任何一次签发错误决定”的概率上界为 alpha。**这不是以已经签发决定为条件的错误率上界**；报告同时显示未决比例，避免选择性汇报。

`adaptive_frontier` 只继续采集上界仍可能超过当前最大下界的候选；它们可能随界限更新重新进入待采集集合。`uniform_all` 每轮继续采集所有尚未到上限的候选。二者使用相同区间与停止条件，区别仅在实验分配。预算不足时均停止并保留未决，不任意降低置信要求。

实现是保守、可审计的有限联合界，不宣称最优样本复杂度，也没有实现 Track-and-Stop 或更紧的无限时域置信序列。背景：[固定置信最佳候选识别](https://proceedings.mlr.press/v49/garivier16a.html)、[时间一致置信序列](https://arxiv.org/abs/1810.08240)。这些文献说明方法方向，不是本项目代码已经获外部验证的依据。

## 原始材料与未知状态

每批计划绑定协议摘要、上一段历史摘要、候选、全体新实验单位、计划运行数和费用预留。完整批次分配先确定，再读取该批结果。每个候选单位保存：

- 任务输入摘要、执行会话 ID、原评估材料摘要、冻结效用规则摘要；
- `observed`、`failed` 或 `unknown`；
- 已知效用、费用、实际启动运行数。

同一批中各候选使用匹配的输入单位；不能跨批重复输入、通过改名把同一输入当新单位，或复用会话。摘要只能绑定提交材料，不能认证原始评估真实性、独立抽样或因果关系。

当前效用是**绑定原评估材料摘要的提交值**，统计层不重新执行领域评分器，因此上界只适用于声明的效用模型，不能直接升级为真实科学错误率保证。`selected_plan_sha256` 始终为 null；非合成材料可给出 `candidate_for_confirmation`，仍需原有评估器完成全部阶段、集成和科学门槛确认。

已知执行失败按事前声明的零效用计入，不能删除或转成成功。未知结果不填零；遗漏记录仍计入已启动分母；未知费用保留上限。部分结果、费用超限或未知均阻断新批次。`assumption_violations` 可在发现漂移或相关样本后保留原历史并撤销统计选择，不修改原协议来掩盖问题。

## 接入方式

先生成可检查的合成示例：

```text
python examples/task-selection/risk_demo.py --output <新示例目录>
python scripts/value_lab.py plan-use <新示例目录/context.json> --output <新计划目录>
```

生成的 `protocol.json` 与 `protocol.sha256` 应独立保留。输入结构见 `schemas/risk-acquisition.schema.json`：

```json
{
  "schema_version": 1,
  "intent": "choose",
  "task_selection": "完整的现有任务选择对象，studies 必须为空",
  "risk_acquisition": {
    "protocol": "生成并经研究者复核的完整协议对象",
    "protocol_sha256": "原协议摘要",
    "batches": []
  }
}
```

上面是结构说明，字符串占位需要换成生成的完整对象。下一批位于 `risk_acquisition.next_block`；实际采集后，把原计划与全部原记录追加为 `{"plan": 原计划, "result": 记录数组}`。尚未返回时使用 `result: null`，下一次先核实原调用。该模式不启动任何模型、插件、科学实验或付费服务。

接入方应核对返回的 `route` 为 `RISK_CONTROLLED_ACQUISITION`，不能只凭版本号推断支持：旧安装可能忽略新增上下文字段。本轮源码与分发包验证不等于已有宿主安装已经更新。

已有使用卡不能事后改造成前瞻确认材料。筛选协议、风险协议和桥接协议分开保存；固定条件中途变化时保留旧研究并重新设计。

## 效率验收：不允许“全不选所以零错误”

`scripts/check_risk_acquisition.py` 预先定义六类合成总体，每类进行 1,000 次配对重复。两个策略共享候选、效用、alpha、epsilon、下限、上限、预算及候选随机流，只改变分配方式。比较身份摘要排除且仅排除分配字段；改变损失容忍、费用或风险不能继续称为同等条件。

每个场景报告签发决定数、错误数、未决率、有用决定率、签发候选的期望损失、实验数及模拟费用。效率通过必须同时满足：

1. 两个方法错误概率的校准上界都不超过 alpha；
2. “均匀策略有用、自适应却没有有用决定”的配对概率上界不超过 3%；
3. 自适应有用决定率下界至少 80%；
4. 配对实验节省的下界大于零。

对六个场景和每场景五个指标分配总计 5% 的比较错误预算。零错误使用保守二项尾界，其余使用 Hoeffding 界；方法分支也分配错误预算。实验差值使用事前上限作为范围，不能看完数据再拿观测极差缩小区间。比较的是独立场景重复下的模拟总体，不是现实科研采用率。

首次冻结场景的结果如下（独立候选实验单位，不是模型 token 或生物样本）：

| 场景 | 均匀平均实验数 | 自适应平均实验数 | 有用决定比例：均匀／自适应 | 效率验收 |
| --- | ---: | ---: | --- | --- |
| 明显分离 | 464.832 | 427.968 | 100% / 100% | 节省下界未大于零，不成立 |
| 少数接近候选，其余明显较差 | 7075.392 | 2621.536 | 100% / 100% | 仅在本合成场景内通过 |
| 多个接近候选 | 9533.568 | 9533.568 | 100% / 100% | 未节省 |
| 全部低于下限 | 789.312 | 789.312 | 100% / 100% | 未节省；正确拒选是有用决定 |
| 恰在效用门槛附近 | 12288 | 12288 | 0% / 0% | 保留未决，不成立 |
| 预算过少 | 192 | 192 | 0% / 0% | 保留未决，不成立 |

通过场景中平均实验数减少约 63%，两种方法各 1,000 次重复均签发有用决定、未观察到错误；保守校准错误上界约 0.71%，并不等于真实错误率为零。其余五个场景不宣称效率收益。原始模拟参数、种子、各项界限与零/未知指标保留在验收 JSON；可通过同一脚本复现。

保存的[校准结果](../evidence/risk-calibration-20261002.json)包含完整协议、种子及聚合结果；[工程验收](../evidence/risk-acquisition-20261002.json)分别记录源码测试、分发包检查和仍未验证的边界。

```text
python -m unittest tests.test_risk_acquisition -q
python scripts/check_risk_acquisition.py --replications 1000 --output <新校准报告.json>
```

局部测试覆盖有限时域超界概率的精确 Bernoulli 递推、停止后追加拒绝、伪重复、效用规则更换、未知费用、抽样漂移、低预算未决，以及真实 CLI / 本地 stdio MCP 入口。真实研究效用、抽样独立性、现场费用节省和宿主安装效果仍需另行验证。

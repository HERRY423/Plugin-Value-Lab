## 价值解释

报告将“挽救/损害”改称观察到的配对改善/退步；旧 JSON 字段为历史重放保留。新研究可以在冻结前添加 `policy.value_interpretation`，明确主要评价目标、任务分布、配对理由及三种评价目标下的五类失败规则。数值评分、系统交付失败、服务商/基础设施问题、未知归因不再依靠单一标签解释。

新报告并列给出科学产物正确性、运行可靠性、完整交付的任务分布成功率差、任务族均权成功率差、缺失范围和描述性族 bootstrap。仍保留全部计划分母；未知及测量失败不能改成已知失败。既有总评和旧研究计算保持不变，新结果不自动获得正向资格。

逐项检查独立列明通过/失败/未知、原始证据限制；费用缺失不抹掉数值诊断，但现金节省、供体真实性和新数据泛化不会由评分通过推导。配对敏感性测试显示：两臂成功序列均为 `[真,假]` 时转移为 0/0；只交换基线重复对应关系，转移变为 1/1，而成功率差仍为零。

# 原有调试方式：参与者任务页

你被分配到 without_pvl 条件。请用自己原有的工具和方法处理观察者分配的真实问题，不查看 PVL 的诊断、参考输出或另一条件的答案。观察者应只转交这张任务页、你的任务材料和中性计时工具；完整评估资料由观察者保管。

目标是解释一项有证据支持的问题，并在可能时完成修复和同条件复测；若没有发现缺陷、证据不足或不值得继续，如实记录。不能为完成任务制造问题。时间和费用停止点按事先与你确认的计划执行。

观察者帮助你在 session.json 填代号、without_pvl、任务编号、配对编号、顺序、之前接触、是否维护者／AI 和计划文件路径，不提供调试帮助。启动 observe.py 后，用 reading、preparation、execution、diagnosis、false_positive_review、repair、retest_preparation、retest 表示实际工作阶段；安装、参考准备或正常对照工作也分别记录 installation、reference、controls。暂停和后台等待输入 pause，恢复时输入当前阶段。

help 记录求助，error 记录错误。understood 要求你自己的问题解释和本地证据文件；credible_retest 要求复测说明和证据。两种标记都待同一套审阅规则确认，不因按了标记就算完成。结束用 completed、blocked 或 abandoned。意外关闭后保留日志并另开一次，不补造丢失的时间。

计时程序启动之前的安装／阅读时间由观察者另行保留原始记录；未知不填零。日志只保存在本地。交回前与观察者确认脱敏范围，不发送密钥、私有数据或未经授权的插件代码。

# Changelog

## Same-version followup and team record extension (0.4.0-alpha.1 retained)

- Added a result followup that identifies the tested research direction, downstream dependencies and directions sharing evidence, without marking a proposed check complete.
- Added a workbench followup form and local CLI output for researcher reassessment after a submitted result.
- Added immutable team usage-card revisions with explicit team decisions, current research context, prior cards and change flags; all cards are recomputed from submitted suite and run records.
- No real research outcome, team adoption benefit or independent authenticity was established.

## Same-version research direction extension (0.4.0-alpha.1 retained)

- Added a host-Agent research-directions skill for task-specific evidence gaps, competing explanations, discriminating next tests and researcher corrections.
- Added local structured-context validation, evidence links, dependency and cumulative resource planning, and context revision comparison; heuristics are not scientific merit or novelty scores.
- Added a seventh read-only MCP tool, CLI artifacts and a researcher-facing workbench with transparent local/Agent reasoning boundaries.
- Retained plugin discovery/connection ownership in Plugin Management, no automatic scanning, model calls, installation or scientific certification.

## Same-version workbench enhancement (0.4.0-alpha.1 retained)

- Added multi-rule validation, calibration examples and local trial grading; exact duplicate/contradictory criteria fail closed while semantic limits remain explicit.
- Added frozen-study comparisons that separate plugin content/version, model, tasks, grading and condition changes; cloning preserves protocols without copying observations.
- Added cost category coverage, explicit allocation, estimate/settlement distinction, human timer reconciliation, unit-success costs and hourly-rate sensitivity. Additional costs enter evaluation and usage-card gates.
- Added immutable analysis revisions, main-view latest-verdict selection, CLI/MCP extensions, and synthetic regression/browser acceptance. No live model study or version increment.

## 0.4.0-alpha.1

- Added a local Chinese evaluation workbench with forms, frozen execution previews, logs, native diagnostics, evidence downloads and scoped usage cards.
- Connected actual Claude native evaluation subprocess execution behind explicit per-study authorization, with budget estimates, frozen plugin copies, process receipts and raw result preservation.
- Added single-attempt execution, cancellation, deadlines, restart interruption handling, evidence hashes and local HTTP protections. No paid retries or publication.
- Added synthetic subprocess and HTTP integration coverage. Native aggregate evidence remains incomplete for full value claims; no live model study is implied.

## 0.3.0-alpha.1

- Added Agent Plugins 1.0.0 root manifests, fixed skill/MCP discovery, official offline schema checks, and OpenAI presentation extension.
- Added Codex and Claude marketplace catalogs, a checked generated plugin copy, a marketplace ZIP and a separate portable ZIP.
- Launch MCP from the bundled script after relocation; separate standard/Codex and Claude root placeholders, with explicit Python/SDK prerequisites.
- Added screenshot-aligned local/Git installation guidance and package/relocated-runtime regression coverage. No public repository or universal-directory submission is implied.

## 0.2.0-alpha.1

- 新增 `use-plugin-well`，按任务需要优先使用原生或已连接能力，缺少外部能力时交接 Plugin Management 或宿主。
- 新增本地 `plan-use` 与 MCP `plan_plugin_use`；区分安装、连接、等待与过期观察，尊重明确服务选择，避免重复建议。
- 新增 `usage-card` 与 MCP `build_plugin_usage_card`，从原始比较记录重新计算，形成绑定版本与执行条件的使用指导。
- 分开访问能力价值与同资料上的质量、效率增益；证据不全、模拟或退步不产生正向使用建议。
- 增加互补指南、三份工作流示例与原生分流自评；保持 Plugin Management 可选，账户动作仍由宿主按明确用户请求处理。
- 本地检查与只读管理信息不代表双插件端到端验收或已证实的用户收益。

## 0.1.0-alpha.1

- 新增通用插件有/无插件比较协议、方案冻结、完整性检查及结果评分。
- 分离 outcome 与 process，保留失败、成本缺失、关键退步和证据上限。
- 支持预先指定质量提升或保持平均质量并降低完整成本的效率目标；效率信号不等同于统计非劣效性。
- 提供 JSON、Markdown、独立 HTML 报告与任务簇探索性不确定性描述。
- 增加人工复核包、保留原记录的复核合并，以及 Claude 原生导出、诊断报告和保守导入。
- 提供 `assess-value` 技能、双宿主清单、可选本地 MCP、科研教学 suite 和原生自评案例。
- 当前为本地 alpha；尚未据此建立真实宿主接受度、用户增益或独立科学有效性。

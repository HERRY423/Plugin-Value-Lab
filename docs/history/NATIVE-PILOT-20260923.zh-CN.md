# 真实双臂科研审计记录（2026-09-23）

本次完成了一个宿主、一个科研任务族的真实采集、评分、登记、导出与离线回放。冻结的六次运行全部有记录，五次正常完成，一次失败；两个配对达到运行完整条件。最终判定为 `INSUFFICIENT_EVIDENCE`，不支持插件有效性或 GA 声明。

## 宿主与输入

- 宿主：Claude Code 2.1.278；实际提供方：本机既有 DeepSeek 配置，原生记录的模型别名为 `deepseek-flash`。模型权重身份未获独立认证。
- 候选：公开 MIT `statistical-analysis` 技能的只读封装，名为 `public-statistical-analysis-audit`。它不是完整上游插件，也没有上游作者参与或背书。
- WITH / WITHOUT 使用相同提示、相同公开表格、相同工具与预算，分别使用独立配置目录及会话；任务顺序交替。三次 WITH 都有原生 Skill 调用，三次 WITHOUT 均未加载目标插件。宿主内置技能仍存在于两臂。
- [公开 airway RNA-seq 结果表](https://github.com/stephenturner/deseq-to-fgsea/blob/master/data/deseq-results-tidy-human-airway.csv)共 64,102 行。按原始顺序取前 16 个有限 p 值及效应值的基因，定义新的小型检验集合，重新计算 BH 校正；结果与 SciPy 独立实现一致。
- [技能来源](https://github.com/kellsaro/k-dense-ai-claude-scientific-skills/tree/main/scientific-skills/statistical-analysis)与数据均保留下载字节摘要，未声称提交号固定。原始数据未识别到仓库许可证，未公开再分发。
- 所有案例都属于同一来源、同一审计任务族，均为开发案例。错误校正值和缺失集合是明确披露的人为错误控制，不是独立生物样本或保留集。

## 冻结规则下的观察

| 场景 | WITH | WITHOUT |
| --- | --- | --- |
| 完整 16 基因表 | 通过全部字段判据 | 错数为 15 行，错误拒绝 |
| 注入一个错误 q 值 | 原生输出 token 上限错误，保留失败 | 拒绝方向正确，但错数为 15 行、错误报告集合不完整，未通过完整判据 |
| 缺失一半检验集合 | 拒绝方向正确，但错数为 7 行，未通过完整判据 | 正确报告 8 行、集合不完整，通过 |

按事前冻结的严格 JSON 字段判据，两臂各通过 1/3 个案例；失败项保留在分母中。报告的描述性分数差为 0，但 `comparison_eligible=false`：一个基础设施失败使整体效果归因不成立，且只有一个任务族，未达到协议的至少两个任务族门槛。不能把描述性差值解释为“已经证明无效”或“已证明等效”。

失败会话输出原生 `<synthetic>` 模型占位符，触发了保守的模型一致性诊断；这不是提供方实际切换模型的证据。原始诊断保留，同时注明根因是输出 token 上限。五个正常完成的会话均通过冻结条件核验。

## 执行历史与成本

第一次准备遇到 Windows 帮助输出编码问题，没有模型调用。随后一个旧协议会话在宿主 US$0.08 原生估算阈值下中止；原始事件和结果未覆盖。修订协议冻结后，用户明确授权六次会话、每次 US$0.75 的宿主中止阈值，合计 US$4.50，并知悉在途请求可能超限。

修订协议第 4 次会话因输出 token 上限失败。检查其已终止且价格信息可估算后，使用单独记录的恢复入口，仅执行原计划未启动的第 5、6 次。失败会话没有重跑，没有新增第七次修订协议会话。总计为六次正式协议会话加一次旧协议失败会话。

Claude Code 对自定义模型的原生 USD 计价标为未知，不能作为真实账单。本次依据[DeepSeek 公开价格](https://api-docs.deepseek.com/quick_start/pricing/)冻结峰时价格：未缓存输入 US$0.30/百万 token，缓存输入 US$0.006/百万，输出 US$1.20/百万；按原生总 usage 与 modelUsage 的逐类别较大值估算，避免错误结果遗漏最后一轮。

## 判定与交付修复

1. 效率目标或要求成本节约时，强制要求完整的补充费用覆盖，不能通过省略开关绕过。
2. 正向公开卡要求保留集本身达到冻结的目标和退化门槛；开发集提升不能替代保留集结果。
3. 发布流程安装签名验证依赖；测试有跳过或未执行测试时门禁失败。
4. 原生采集保存输入、插件、会话、技能调用、模型、token、答案和失败证据；对未知状态拒绝自动重试，明确恢复只允许尚未启动的计划项。
5. 真实失败暴露的绝对路径诊断已改为稳定相对引用，无效 JSON 结果也能迁移回放。旧登记与旧导出保留，新评分以同一研究修订追加。

# 让证据在需要时出现

2026-10-01；版本保持 0.8.0。这是既有插件组合报告的交互改进，不改变评分、任务可行性或最小插件选择，不是实时宿主监控。

## 先看与下一步有关的证据

既有 plan_plugin_use 的组合结果新增 evidence_brief。摘要从本次重算的报告产生，保留证据类型、已收到/计划记录数、原规则候选、未满足或未知候选、当前问题和展开目标。它不把收到记录叫作完成任务，不把低上下文占用叫作可信，不把完整合成结果叫作真实采用证据。

优先提示：需要核对的记录或比较条件 → 缺少运行 → 可行性未知 → 没有合格候选 → 负担信息缺失 → 具体取舍 → 可供复核的比较。费用缺失、耗时缺失、任务失败、未知可行性、负担缺口分别保留标记，不合并成一个红黄绿状态。更高优先级问题不会删除其他标记或原始报告中的失败。

取舍摘要最多展示前两个取舍对及其优势方向，并明确是部分任务上的差异；全部取舍在展开后保留。指标互相抵消或同一指标跨任务反转时，不宣称某指标全面更优。原推荐候选始终单独保留，不根据展示重新选择。

## 再展开具体依据

既有 plan-use 同时生成 plan.json、PLAN.md 和 EVIDENCE.html。文字报告顶部展示证据摘要；HTML 首屏展示问题、失败/未知标记、取舍摘要和一个相关入口。其余内容使用原生 details/summary 折叠：

- 候选为什么满足或未满足原要求。
- 各候选对的具体任务、指标及差值。
- 缺少的负担字段与每次运行的上下文采样覆盖。
- 原评分器报告的完整性与条件问题。
- 全部评分记录，含失败、缺失及原始问题文本。
- 来源摘要、口径及完整分析文件入口。

点击首屏入口会打开对应部分，并把键盘焦点移动到标题；Enter 可继续展开/折叠。初始页面不展开所有表格。通过带片段的链接打开页面也会展开相应部分。无 JavaScript 时仍可手动使用原生折叠控件。窄窗口内表格允许横向滚动。

页面离线可用，无外部资源、网络请求、计时器或自动执行。用户材料进行 HTML 转义，页面脚本内容固定并使用 CSP 摘要授权。它展示报告快照，未认证宿主执行或实时状态；完整分析数据不等于原始宿主日志，后者仍需独立保留。缺失数据保持未知。

## 演示

```text
python examples/plugin-combinations/burden_demo.py --output NEW_DIRECTORY
```

每个场景生成 EVIDENCE.html；打开 tradeoff/EVIDENCE.html 查看取舍，打开 missing/EVIDENCE.html 查看缺失材料提示。所有演示均为制造数据，真实插件收益、自动宿主采集、真人阅读效率及统计显著性未建立。当前插件目录中的已安装副本不会因修改源码自动更新。

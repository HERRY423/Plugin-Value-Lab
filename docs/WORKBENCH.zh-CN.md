# 评估工作台 · 0.6.0

工作台把方案准备、Claude Agent 执行、原始证据留存和已有报告引擎串起来。它不是模拟执行按钮：授权启动后会启动本机 `claude plugin eval` 子进程，调用已配置 Claude 账户中的模型。没有启动授权时不会调用模型。

## 打开与使用

需要 Python 3.11+；工作台本身没有第三方依赖。真实执行还需要 Claude Code 2.1.269+、可用的账户认证及模型权限。

```powershell
python scripts/value_lab.py workbench --data .\work\workbench --port 8766
```

打开终端显示的 `http://127.0.0.1:8766`。如本机只解析到 PowerShell 启动脚本，工作台会尝试 npm 包中的实际 Claude 可执行程序；也可启动时传 `--claude <完整可执行程序路径>`。启动参数只接受本地程序路径，网页不能提交任意执行命令。

“研究方向诊断”页可在新结果出现后定位需要重新审视的方向和依赖；“团队使用记录”页可从已有评估生成逐次保留的使用卡，附上研究上下文与团队决定。两页的结构检查和记录保存不调用模型，也不自动执行研究或插件管理动作。详见 [研究方向指南](RESEARCH.zh-CN.md) 与 [团队使用记录指南](TEAM-RECORD.zh-CN.md)。

1. 填插件文件夹、账户可用模型、重复次数和本次美元估计上限。填写正常任务、负向任务或应弃权任务与判定标准。判定标准是输出包含、不包含指定文字，或模型评分规则；模型评分不会代替人工评审。
2. 点“冻结并预览执行方案”。工作台只做本地版本/接口检查，复制插件、导出评估任务、记录哈希和命令。此时没有模型调用，也没有验证账户认证或模型权限。
3. 检查任务、插件快照的排除项、模型、估计上限和发送范围，然后授权“开始真实评估”。插件代码本身需要可信；插件钩子可能以本机用户身份执行。
4. 查看日志。停止操作会尝试终止整棵子进程树并保留已有结果。一个冻结方案只启动一次，刷新页面不会重跑。无结果、调用错误、部分评估、解析异常与成功返回分开显示。
5. 下载原始 JSON、执行回执、方案锁、哈希清单、诊断报告、Value Lab 报告与使用卡。HTML 以附件下载，需单独打开；未知原生字段保留在原始文件中，不猜测含义。

“体验模拟示例”只生成教学数据，始终显示 `SIMULATION_ONLY`，不经过真实 Claude 子进程，也不产生模型费用。

## 必须保留的限制

**接通了执行和原始证据采集，不等于原生汇总已经满足完整价值研究契约。** 当前官方 v1 汇总字段不足以建立逐次会话身份、实际插件加载、冻结条件的逐次观察、最终输出与所有本地评分规则的一一映射。已有导入器仍将这些标记为缺失。即使原生分数很高，正式报告也可能是 `INSUFFICIENT_EVIDENCE`。这不是执行失败，也不会被自动改为正向推荐。

工作台请求 `--verbose`、`--debug-file`、`--keep-temp` 留下可用日志与临时工作空间，但不把自由文本日志猜译为认证过的逐次观察。临时目录保存在研究目录的 `tmp/`；可本地检查，不通过网页暴露。日志与文件可能包含任务内容，分享前应人工检查。凭据通过子进程环境继承，不写入启动回执；第三方插件可能自行打印内容，因此日志不保证无敏感信息。

默认 MCP 是模拟环境：不能据此验证真实数据连接或服务效果。Windows 下首版不开放 Shell；需要这些能力时应另建明确环境与权限的执行后端。插件副本不自动安装依赖；快照排除 `.git`、`.venv`、`node_modules`、`work`、`dist`、`build`、嵌套 `plugins` 等目录，清单可在冻结预览中检查。遇到依赖这些目录的插件，使用已准备好的独立包，不要把残缺快照当成同一运行条件。

费用上限是原生的估计检查，进行中的模型请求可能造成超出；不是结算硬上限。本工作台串行启动研究，每个原生执行的并发数为 1，无付费重试。停止和崩溃可能使费用未知，不能把未知当作退款或零支出。程序重启后不会主动终止可能仍在运行的旧 PID，也不会据 PID 数值去杀死其他进程。存在未核对的中断研究时阻止新的付费启动，需要操作者先核对原进程和费用；当前版没有自动恢复/续跑功能。

## 本地接口与安全边界

仅绑定 `127.0.0.1`，校验 Host、Origin 与修改请求的随机令牌，无跨域授权。仅可下载当前研究列出的本地证据；拒绝目录穿越和链接路径；HTML 不作为同源可执行内容提供。每个数据目录有进程级独占锁，避免两个工作台重跑同一研究。这是单用户本地工具，不是可暴露到公网的多租户服务。哈希只能验证本地字节一致性，不能抵御能够同时修改所有本地文件的攻击者，也不证明研究独立性。

API：`GET /api/studies`；`POST /api/studies` 准备并冻结（表单字段或完整 suite）；`GET /api/studies/<id>`；`POST .../start` 需要当前 `frozen_sha256` 和 `authorize_execution=true`；`POST .../stop`；`GET .../files/<name>` 下载；`POST /api/demo` 生成模拟示例。没有自动模型调用的 GET 接口。

## 验证范围

自动测试用独立 Python 子进程制造原生结果，包括成功返回、部分结果、错误、超时/停止和无效 JSON；这些是软件工程测试，没有调用真实模型。版本与原生接口检查可在本机真实 CLI 上做只读验收。真实插件效果、模型账户执行、独立人工结果均需另行真实运行；不能把工程测试当成这些证据。

原生行为依据：[Claude Code Plugin evals](https://code.claude.com/docs/en/plugin-evals)。

# 数据治理说明｜机构内试用

生效：2026-10-20。适用于 Plugin Value Lab 的 L0/L1 试用。**原始数据、受限数据及未发表内容留在机构批准的计算与存储环境；对外只提供经人工批准的最小派生产物。** 本页是项目处理要求，不是合规认证或软件已阻止外发的证明。

**运行前由实验室指定数据负责人。** 在机构内记录用途、数据分级、允许访问者、模型与插件出口、保存位置、保留/复核日期、备份清理方式及审批依据。研究者负责执行，机构数据/伦理/安全负责人决定可用范围；预算或模型调用授权不能替代数据使用和出口批准。

**“本地”覆盖整条路径。** 受限内容只交给机构内模型和已核对出口的工具；检查 agent 宿主、评委模型、检索、遥测、崩溃报告、会话历史、同步盘与备份。实验室自有的外部 API 账户仍是机构外接收方，不能用于本次机构内受限数据试用。未经批准不将输入、输出或日志贴到聊天服务、GitHub、CI 或支持工单。使用机构防火墙/出口控制与受控存储；PVL 的适配器及本地文件并不自行实现全面隔离、加密、访问控制或自动防泄漏。

| 产物 | 默认处理与对外条件 |
| --- | --- |
| 原始数据、逐人记录、映射密钥、完整提示词/回答、任务输入、日志、截图、缓存、备份 | 留在机构内；不导出整个工作目录、原始会话或冻结方案。密钥不得进入证据文件。 |
| 使用卡、汇总指标、费用/耗时、停止原因、失败与 UNKNOWN 摘要 | 默认内部；数据负责人逐项检查后，仅导出必要摘要，去除身份、私有路径、未发表细节及可重识别的小群体信息。保留阴性与缺失状态，不改写结果以便分享。 |
| 软件版本、公开配置模板、许可允许的合成示例、L1 完成证明 | 内容核对并获出口批准后可分享；证明用不含私人身份的实验室代号和审批引用，原始证据由机构保管。哈希只绑定内容，不构成匿名化。 |

**人类受试者数据。** 使用前由机构确认伦理/同意、数据使用协议与研究目的是否覆盖本次评估。姓名、病历号、临床自由文本、原始序列、可识别影像及带关联键的编码个体数据，不进入普通 PVL 记录或 agent 提示。需要这些数据的任务在另行批准的受控系统处理；PVL 只接收经机构审查的最小汇总。换编号不等于匿名化；罕见事件、小群体及跨表关联风险仍需审查。批准缺失或风险不明时暂停该数据用途，不能默认放行。

**未发表数据与稿件。** 默认按保密材料管理，包括假说、结果、样本标识及可透露结果的检索词。先用公开或合成材料演练；实际试用仍在机构内完成。成果归属、合作方约定、专利/发表限制及可公开摘要由权利人确认，插件作者不因技术支持而取得访问或发布权。

**导出与退出。** 在独立导出目录逐文件审查正文、附件、元数据、文件名、路径与嵌套归档；记录接收方、用途、批准人、日期及文件清单，只发送获准版本。原始证据可留机构供受控核验，不以公开原始数据作为 v1.0 验收条件。按机构期限管理原件、日志和备份；发现误记录/误外发立即停用相关出口、限制访问并走机构事件流程，获授权后处置各副本。PVL 不自动删除远端副本，也不替机构作伦理、匿名化或法律判断。

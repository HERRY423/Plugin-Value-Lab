# PVL 能否改善插件采用决策

供实验室协调人使用的配对盲评先导方案。研究对象是评审者对一个明确用途作出的决定。两条路径使用同一份原生宿主证据，一条按实验室惯常方式做专家复核，另一条在相同条件下增加 PVL。本目录只含空表。首个外部 L1 测的是被测插件，完成证明与本研究分开保管。[外部 L1](../../first-lab-l1/ACCEPTANCE.md)

## 1. 在任何人看见研究结果前冻结

在机构内复制本目录。协调人填写下表、建立分配表并保存带日期的只读版本、文件摘要及机构存证引用。先导的目标是估计本实验室在明确任务范围内的决策差异。只使用已获准二次审阅的真实留存记录。若尚无记录，状态为待开展。

| 填写项目 | 由协调人实填 |
|---|---|
| 研究编号、机构内负责人、操作日期与批准引用 | |
| 目标用途、候选插件及版本、宿主版本、PVL 版本和本地改动摘要 | |
| 纳入与排除规则、抽样来源、任务族划分、计划族数及每族案例数 | |
| 真实记录的来源及开发者、评审者既有接触。事先排除调校过的案例 | |
| 两条路径共同可用的资料、原生评测工具及版本、惯常专家复核步骤 | |
| 判据与界线（达到何种效果可用于该用途，哪些关键错误或退步必须拒绝，哪些缺口应暂缓） | |
| 两组相同的人工时间和现金上限、停止条件、计时起点、计费币种、共享费用分摊 | |
| 评审者与领域专家资格、利益冲突、分组随机方法与留存凭证、盲态负责人 | |
| 最小有意义的正确决策差、可接受的错采上限及成本差。如只做可行性先导，注明仅描述 | |
| 冻结时间（含时区）、登记位置、允许导出的匿名汇总 | |

每个案例对应一个“候选插件 × 限定用途”决定。协调人对等提供任务说明、相同的有／无目标插件产物及失败轨迹、原生评分、已知成本和冻结判据。共用材料建一份清单并登记摘要。协调人清除能透露参考标签、先前采用决定或 PVL 输出的批注。同源输入、变体和重复运行归入同一任务族。领域参考可以使用额外的独立科学标准或预留复测证据，在冻结时说明其来源和适用范围，封存独立参考包并登记其摘要，仅交给裁决专家。

## 2. 分配与独立作答

1. 将非作者评审者按领域经验配对，每对负责同一组案例。协调人对每对人员独立掷币或用事先约定的随机方法分配一人为原生复核、另一人为原生复核加 PVL。每人全程只走一种路径，同一对按分配表预定的行序审阅案例。人员只剩一对时，将人员差异列为限制。任务族、案例和人员分配先于结果固定，不因困难换题或换人。
2. 每个案例在私有的 [分配表](allocation.csv) 中占一行。两位评审各用一个无含义的提交编号，两位裁决专家使用另一个盲编号。协调人持有组别映射和两组材料。评审者只接收自己路径的说明、相同的原生包及自己的空白[决策表](decision.csv)。两条路径独立作答，评审者知道自己能使用的工具。原生组和裁决专家均不得提前看到 PVL 判定或对方输出。
3. 两组都按实验室的常规专家复核流程判断。PVL 组可以在原生包上运行冻结版本的本地 PVL 检查，记录所用命令、版本、失败和人工更正。双方均可作出 `ADOPT`（限于冻结用途）、`REJECT` 或 `DEFER`（证据不足）。L1 的“进入先导”只支持进一步试验，评审者须单独按研究判据作答。每次锁定首次结论、理由、依据与时间。保留超时、中断和未运行的槽位。失去盲态、暴露参考答案或获得额外帮助须记录。
4. 从阅读、准备及安装开始计时，计入误报复核、同事协助、重试、失败和复查。主动劳动按参与者累加，日历经过时间单列。现金分结算、估算、未知。协调人另存共同准备与独立裁决账本，按冻结权重分摊一次，分别报告研究共用成本与两条路径的增量成本。每一笔保留凭据引用。缺数填 `UNKNOWN`，零费用要有依据。可复用既有[工时与费用账本规则](../../pseudobulk-author-pilot/BURDEN.md)，此研究以同一记录配两位评审。

## 3. 盲态裁决与开盲

两位独立领域专家分别在隔离的[参考表](reference.csv)中评同一案例。他们不参与上述两组评审，也看不到评审建议、PVL 报告、组别、对方标签和作者结论。使用同一冻结质量判据及约定的独立科学依据。首轮各写一行 `stage=independent`，保存时间、标签与证据。认可“需要更多证据”的参考标签为 `DEFER`。专家无法裁决时标 `UNKNOWN`。

保留首轮原件，报告四类标签的交叉计数与原始一致率。若有分歧，先在盲态下由两位专家记录理由并尝试达成一致，可按冻结的规则请第三位专家仲裁。每例另存一行 `stage=final`。无法解决则为 `UNKNOWN`。协调人确认两组答案及参考均已封存后才合并各表，记录开盲时间、退出、既有暴露及任何破盲。一旦答案泄露，保留该例并单列影响。

## 4. 按冻结分母计算并报告

- **主要指标为计划案例中产生可确认正确决定的比例。** 某案例参考标签可判定、评审提交有效且与参考完全相同，计 1。其余计 0，包括未提交与参考未知。这是交付了多少可证实的正确决定。逐臂同时列出“已确认错误”“流程未完成”“参考不可判定”的计数，避免把所有 0 解读为科研错误。
- 每个任务族分别用两臂各自的得分之和除以该族计划案例数，报告“原生加 PVL 减原生”的族内配对差，再以各任务族等权计算总体差。另做缺失敏感性分析，对无法确定正确性的槽位分别取 0 或 1，效应下界取 PVL 的下界减原生的上界，上界反之。标明这是保守的缺失结果范围。列出每个任务族的样本数与差异。极少任务族或同一对评审反复作答时只作描述。
- **错采**报告参考为 `REJECT` 时评审选择 `ADOPT` 的数量／该类参考总数。**错拒**报告参考为 `ADOPT` 时评审选择 `REJECT` 的数量／该类参考总数。完整列出三类决定与参考的交叉表（另列未提交和未知），特别列出参考要求暂缓却直接采用的情况。零分母记为不可估。逐组报告暂缓率、完成率、预算超限和关键科学错误的实例及依据。
- 对照正确性与漏错后，再比较每族的人工秒数、现金及两者的配对差。工时与现金分别报告。只有质量达到预设可接受范围且成本资料完整时才解释效率优势。一并报告每笔未知、共享投入和失败成本。
- 后续如要作确认性结论，应在增加样本前固定独立任务族及评审团队的抽样、样本量依据和区间方法。重复案例或共享评审者会造成相关性，不能将明细行当作独立样本。另一实验室的重复研究另行冻结并独立报告。此次先导仅评估基于给定记录的决策准确性，真实采用后的长期效益需要后续观察。

**开跑所需材料**为获批可用的未见真实任务族、原生运行包、两组非作者评审者及独立领域专家、冻结判据和可核对的成本上限。机构内使用代号与证据引用，保留原始资料。对外仅交经批准的汇总及研究局限。[数据治理](../../../docs/DATA-GOVERNANCE.md)

### 表单填写约定

三个 CSV 只有表头。在分配表中 `review_pair_id` 表示配对的两位评审，`route_a/b` 填 `NATIVE` 或 `NATIVE_PVL`，`packet_sha256` 绑定两组共用的原生包。决策表每个预定提交编号占一行，`status` 填 `completed`、`blocked`、`abandoned` 或 `not_run`，未完成的 `action` 留空，`notes_ref` 指向中断、帮助、超限或破盲记录。时间戳含时区，`cost_basis` 填 `settled`、`estimated` 或 `unknown`。参考表以盲编号汇合，只写机构内证据引用。各人只填写自己的副本，协调人保存原件及最终合并记录。
